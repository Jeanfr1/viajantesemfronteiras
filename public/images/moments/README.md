This folder contains travel moment images.

Image Guidelines:
- Format: JPG or WebP
- Resolution: 3000px width recommended
- Aspect ratio: 16:9 or 3:2 preferred
- File size: Optimize images to be under 500KB
- Naming: Use descriptive names (e.g., beach-sunset-thailand.jpg)

Example structure:
```
moments/
  ├── europe/
  │   ├── paris-eiffel.jpg
  │   └── rome-colosseum.jpg
  ├── asia/
  │   ├── bali-beach.jpg
  │   └── tokyo-street.jpg
  └── americas/
      ├── peru-machu-picchu.jpg
      └── brazil-rio.jpg
```
